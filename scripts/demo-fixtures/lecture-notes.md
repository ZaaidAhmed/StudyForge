# Software Design — StudyForge demonstration notes

The Strategy pattern defines a family of algorithms, encapsulates each one, and makes them interchangeable. The context delegates work to the selected strategy instead of hard-coding one algorithm.

The SOLID principles support maintainable object-oriented design. The Single Responsibility Principle gives a class one reason to change. The Open/Closed Principle keeps existing behavior open to extension without modifying stable code. Dependency inversion recommends depending on abstractions rather than concrete implementations.

The Observer pattern lets an object notify interested dependants when its state changes. A good design keeps responsibilities explicit, boundaries small, and evidence traceable to the source material.
